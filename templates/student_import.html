School Migration / Opening Dues

View Migration Control Totals

Moving from another school system? Use the existing tenant-scoped Student Excel / CSV Import. The template includes one Opening arrears column per configured fee head (Tuition, Annual Charges, etc.). Import only the amount still unpaid at the migration cutover date.

  1. Configure campus, classes, academic session, fee heads and fee plans first.
  2. Download the template below and fill one row per student. Use the Students worksheet only.
  3. For each fee head enter its unpaid opening balance after deducting payments already received.
  4. Upload, map columns, review validation errors, and confirm the complete batch.

Historical paid amounts: Keep old receipts and their dates in a separate register. This import does not post historical payments to cash, create receipt history, or automatically reconcile opening balances to the general ledger. Never add paid amounts to opening arrears.

Example: Tuition Rs. 3,500; already paid Rs. 1,500; unpaid Rs. 2,000. Enter 2,000 under Opening arrears — Tuition.

1. Download School Data Excel Template

School owners: download this file directly from SchoolFlow. You do not need to request an Excel file from the software owner. The template is generated using your own school's configured campus, classes, sessions, fee heads and fee plans.

Download Student & Opening Dues Excel (.xlsx)

Download Old Payments Register (.xlsx) — reference only

How to fill: Open the downloaded file. In the Students tab, enter one student per row. Keep the headings unchanged. Enter name, admission number, parent details, campus, class, session, fee plan and each unpaid amount under its matching Opening arrears column. Read the Instructions tab for valid choices.

Example: Fee Rs. 3,500, paid before migration Rs. 1,500, remaining Rs. 2,000 → enter Rs. 2,000 as Opening arrears. Do not enter Rs. 1,500 as a new payment.

After upload: Match columns, fix any highlighted errors, review and confirm import. Students and fee plans are then saved; dashboard counts may update after refresh. Verify opening dues in the fee screens separately. Historical payments can be uploaded separately as non-posting reference records.
